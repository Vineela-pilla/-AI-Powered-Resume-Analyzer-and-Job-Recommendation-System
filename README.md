# -AI-Powered-Resume-Analyzer-and-Job-Recommendation-System
Description: Developed an AI-powered application that analyzes resumes using LLMs and compares candidates' skills with job descriptions to recommend suitable job roles.
Key Features:
- Upload resumes in PDF format.
- Extract skills, education, and experience.
- Use prompt engineering to compare resumes with job descriptions.
- Generate skill-gap analysis and improvement suggestions.
- Recommend suitable job roles.
Technologies: Python, Flask, LLM, Prompt Engineering, LangChain, Streamlit.
